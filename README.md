# PC-Power-Monitor ⚡

## Présentation
Ce projet est un outil open-source destiné à la surveillance de la consommation électrique et à l'automatisation de la gestion d'énergie pour les configurations matérielles et les petits systèmes connectés.

## Fonctionnalités prévues
* Suivi en temps réel des besoins énergétiques des composants.
* Scripts d'automatisation pour optimiser la consommation.
* Interface de lecture simplifiée des données matérielles.

## Technologies envisagées
* Python
* Scripts shell
* Intégration API (en cours de développement)

## État du projet
Projet en phase initiale de conception. L'intégration de modèles d'IA pour l'analyse des journaux de données et l'optimisation des scripts est prévue pour la prochaine version.
